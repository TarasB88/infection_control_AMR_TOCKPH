# Google Sheets — публічне читання без запису з дашборду

## Архітектура

- Дані зберігаються в одній робочій книзі Google Sheets.
- Дашборд читає книгу напряму через Google Visualization endpoint.
- Книга налаштована як **Anyone with the link — Viewer** («Усі, хто має посилання — Читач»).
- Google OAuth, Google Sheets API write scopes, service account, client secret, private key, Apps Script, Cloudflare D1 та серверні мости не використовуються.
- Дашборд не має функцій запису в Google Sheets.
- Для додавання й оновлення даних використовуються Google Forms, прив’язані до тієї самої книги.

## Підключення книги

1. Відкрийте робочу Google-книгу.
2. У Google Drive натисніть «Поділитися».
3. У загальному доступі встановіть «Усі, хто має посилання».
4. Роль встановіть **Читач**, не Редактор.
5. Скопіюйте посилання на книгу.
6. У дашборді натисніть «Оновити дані» та вставте посилання. ID книги збережеться локально в браузері для наступних відкриттів.

## Формат аркушів

Дашборд читає такі точні назви аркушів:

- `Facilities`
- `Facility_IPC_Profile`
- `IPC_Assessments`
- `Legal_Acts`
- `Training_Events`
- `Training_Facility_Stats`
- `AST_Data`
- `WGS_Staging`
- `Dictionaries`

Відсутні аркуші не створюються автоматично. Вкладки, які не входять до цього переліку, не читаються.

## Заголовки колонок

Перший рядок кожного аркуша — технічні ключі, наприклад `Hospital_ID`, `Sample_ID`, `SIR_Category`. Він є заголовком, а не записом даних.

Код використовує технічні ключі для зіставлення полів. Людинозрозумілі українські назви показуються тільки в таблицях і формах перегляду. Не перейменовуйте технічні ключі без одночасного оновлення словника мапінгу в застосунку.

Якщо в книзі є повторний рядок із тими самими ключами, він не повинен відображатися як запис.

## Внесення даних

Використовуйте Google Forms, пов’язані з відповідними аркушами книги. Перевірте, що форма додає відповіді саме до потрібної вкладки та не змінює рядок технічних заголовків.

Дашборд не виконує запис, імпорт Excel, створення вкладок або редагування рядків. Кнопки оновлення лише перечитують дані з Google Sheets.

## Безпека

Публічний доступ Viewer поширюється на всю книгу, а не на окремі аркуші. Кожен, хто має посилання, може прочитати всі дані книги. Не зберігайте в ній відкриті паролі, персональні дані чи прямі ідентифікатори пацієнтів. Для `Patient_ID` використовуйте погоджені псевдоніми.

Якщо дані не можуть бути доступні всім, хто має посилання, публічна схема читання не підходить — потрібна інша архітектура доступу.
